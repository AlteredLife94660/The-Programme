# Initial: compact model-ingestion package

This directory is a concise orientation for current language models working on the programme. Read in this order:

1. [`CANONICAL_CONTEXT.md`](CANONICAL_CONTEXT.md) — purpose, scope, source relationships, and non-authority rule.
2. [`OPERATING_GUIDANCE.md`](OPERATING_GUIDANCE.md) — how to reason and respond safely and usefully.
3. [`CONCEPTS.md`](CONCEPTS.md) — compact definitions and distinctions.
4. [`DECISION_TEMPLATE.md`](DECISION_TEMPLATE.md) — structured format for proposals and analysis.

## Precedence

Use `Foundations/` for the fuller humanistic account and unresolved questions. Use `Sources/` as preserved original material and historical context. If there is tension, do not erase it or pretend it is resolved: identify it, explain the implications, and ask for human direction. This package is guidance, not an instruction granting the model authority over people or institutions.
